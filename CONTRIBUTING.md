# Contributing to MartinMart

1. Clone the repository.
2. Install JDK 17 and Maven.
3. Create local configuration from `.env.example`; keep `.env` ignored.
4. Run `mvn -B clean verify`.
5. Create `feature/<name>` branch.
6. Implement feature with tests and docs.
7. Use conventional commits: `feat:`, `fix:`, `test:`, `docs:`.
8. Open a self-reviewed pull request.
9. Merge only after CI is green and the Definition of Done is satisfied.
