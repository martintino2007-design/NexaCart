# NexaCart — Run in VS Code

1. Extract the ZIP.
2. Open the `NexaCart` folder in VS Code.
3. Open `index.html`.
4. Install **Live Server** if needed.
5. Right-click `index.html` → **Open with Live Server**.

The redesigned browser UI runs without Maven/Tomcat and includes marketplace, bag, orders, seller studio, admin, account and MartinBot demo functionality. The Java backend remains under `src/`.
